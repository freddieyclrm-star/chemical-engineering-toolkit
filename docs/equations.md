# Engineering Equations  

## Unit Conversions  

### Temperature  
T(K) = T(°C) + 273.15  
T(°C) = T(K) - 273.15  

T(°C) = (T(°F) - 32) * 5/9  
T(°F) = T(°C) * 9/5 + 32  

T(K) = (T(°F) - 32) * 5/9 + 273.15  
T(°F) = (T(K) - 273.15) * 9/5 + 32

## Mass Balance  
Σ m_in − Σ m_out = 0  
mass fraction[i] = mass[i] / total_mass  
mass flow = density * volumetric flow  

## Energy Balance  
Q = m * cp * ΔT  
Q = m * L  
Q = reaction rate * reaction enthalpy  
heat imbalance = Q_hot − Q_cold
